# CEDA-T reproduction materials

This repository provides reference code and archived case-level results for the CEDA-T study. The executable workflow recalculates the statistics in Tables III–IX and the five-case parameter/seed-stability summaries.

## Run

Python with NumPy is required. From the repository root, run:

```bash
python run_all.py
```

Results are saved under `results/run_001/` (later runs use the next available number). This command **generates results only**; it does not check recorded file hashes or compare generated values with paper tables. To optionally compare against the saved reporting values, run:

```bash
python run_all.py --verify
```

The optional check is for independent review and is not needed to calculate the results.

## Contents

- `tables_III_IX/`: archived per-case records, table aggregation and confidence-interval procedures.
- `c10_stability/`: five-case parameter and training-seed observations with aggregation scripts.
- `source_reference/`: available neural and BSM implementation components, not a complete training runner.
- `data_generation/`: description of synthetic benchmark generation.
- `configs/`, `seeds/`, `splits/`: recorded settings and the available partition records.
- `REPRODUCIBILITY.md`: scope and known limitations.

The scripts **reaggregate saved observations**. They do not regenerate the original datasets, train the neural models, run CCI attribution, or simulate the plants from scratch. Historical sample-level splits for Tables III, V and IX were not preserved; the later strict-protocol splits are provided separately. SEEK-Sim expert-action labels are generated by rules, not by human expert scoring.
