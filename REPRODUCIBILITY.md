This package supports **statistical reproduction from archived case-level results**. By default, `python run_all.py` recalculates Tables III–IX, the archived pairing-cluster confidence intervals, and the five-case C10 parameter/seed-stability summaries. No recorded-file checksum or comparison with submitted table values is required for this calculation. An optional `--verify` flag compares the newly calculated numbers with the stored reference values.

This workflow does **not** run the original data generators, neural training, raw CCI attribution, or closed-loop BSM simulations. Neural and BSM files under `source_reference/` are reference components, not an independently runnable historical end-to-end pipeline. The original sample-level split indices for historical Tables III, V, and IX were not preserved; later strict-protocol partitions and BSM pairing-group records are included. Some historical effective configurations and random-number states are incomplete.

The two relative-EQI-reduction percentages in Table VIII's note (4.2% overall and 7.1% storm) are not independently recomputed from distributable pre-repair denominators in this package; the saved table-body aggregates and intervals are reproduced here.

SEEK-Sim contains rule-generated synthetic expert-action labels, not human-rated decisions. See `data_generation/DATA_GENERATION_PROCEDURE.md` for the simulator and benchmark distinctions.
